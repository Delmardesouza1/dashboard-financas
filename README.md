# 📊 Dashboard de Análise Financeira (Python)

Uma solução desenvolvida em Python para consolidação, tratamento e visualização de dados financeiros operacionais. O projeto automatiza o processamento de transações, faturas de cartão de crédito e cupons fiscais, gerando relatórios consolidados em HTML, CSV e Excel.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Processamento de Dados:** Pandas / OpenPyXL
* **Geração de Relatórios:** HTML, CSV e XLSX

---

## 📌 Funcionalidades Principais

* **Consolidação de Transações:** Leitura e unificação automática de extratos bancários e faturas de cartão de crédito (Nubank e outros formatos).
* **Processamento de Cupons Fiscais:** Leitura e integração de dados extraídos via OCR/Visão Computacional.
* **Métricas Financeiras Automatizadas:**
  * Cálculo do gasto total e quantidade de lançamentos.
  * Identificação automática de oportunidades e potenciais de corte de custos.
* **Exportação Multicanal:** Gerador de relatórios visuais interativos em HTML e planilhas analíticas em Excel/CSV.
